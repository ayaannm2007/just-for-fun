# Just For Fun

Two small animations made with plain HTML and JavaScript. Nothing to install: open them in a browser.

| | |
|---|---|
| **The Connection** (`eyes/`) | Two eyes drawn entirely with ASCII characters. They blink and follow your mouse or finger, then the camera dives into a pupil to show what's inside. |
| **One Heart** (`heart/`) | "I love you" in more than 80 languages (Bangla included), written word by word into the shape of a heart, which then starts beating. Tap to write it again. |

**Live:** https://ayaannm2007.github.io/just-for-fun/
